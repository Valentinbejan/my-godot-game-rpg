# The Hollow Star - Sunken Cloister

A first-person dark-fantasy prototype with exploration, spells, dialogue, combat, and progression.

## Contents and current limits

The Godot project is at tullianum-carcer/project.godot. Demo scripts, scene resources, and tests are included. Local texture/audio libraries and binary art sources are omitted. Required texture paths and attribution are listed in tullianum-carcer/THIRD_PARTY_NOTICES.md. This source selection is incomplete for play without its local media.

This is a curated public copy of the local project. Publication documentation
exists only in this separate copy. The original project is not modified.
Imported source files retain their original relative paths and contents.
No prior Git history, credentials, local caches, backups, or bundled tools
are included.
